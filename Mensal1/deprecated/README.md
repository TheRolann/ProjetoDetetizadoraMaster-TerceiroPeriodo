# Versões antigas

Esta pasta preserva implementações e protótipos anteriores do projeto, para consulta da evolução acadêmica.

O Maven compila o código atual de `src/main/java`. Não use os arquivos desta pasta para iniciar a aplicação nem execute o script SQL antigo para configurar o banco atual.

As instruções de execução e as migrações válidas estão no README da raiz e em `src/main/resources/db/migration`.
